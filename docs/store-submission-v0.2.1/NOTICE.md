# 제3자 자료와 원자산 고지

이 저장소의 코드와 그 코드에 포함된 문서는 저장소 루트의 [Apache License 2.0](../../LICENSE)을 따릅니다. 아래 자료와 이 저장소의 이미지 산출물은 그 라이선스 범위에 자동으로 포함되지 않습니다.

## 이미지·NVA 자료

이 후보에는 NVA(아바타 설명 파일)나 VRM 바이너리 원본 파일을 포함하거나 원본 형태로 재배포하지 않습니다. 별도 원자산 metadata 검토에서 Naia, Jina, Minho 계열 NVA의 원자산 소유자는 Nextain이며, 해당 manifest에 표시된 조건은 CC BY 4.0으로 확인되었습니다. Jina의 실사풍 캐릭터는 Vertex AI로 생성된 합성 성인 캐릭터로 기록되어 있으며 실존 인물을 재현한 자료로 취급하지 않습니다. 이 확인은 해당 manifest와 그 manifest가 가리키는 자산에만 적용됩니다.

이 디렉터리의 `rework/master/` PNG는 스토어·문서 검토용 이미지 산출물입니다. 이미지 안에 들어간 배경, 캐릭터, 로고, 화면 캡처, 폰트와 상표의 권리는 각 원자산 소유자와 원래 조건을 따릅니다. 이미지에 표시된 공개 제품 화면이 있다고 해서 화면 속 원자산을 별도로 재배포할 권리가 생기지 않습니다.

`03-OL_Woman.vrm`의 동봉 VRM metadata에는 author가 VRoid Project이고 title이 `AvatarSample_A`로 기록되어 있습니다. 해당 provider metadata는 기업·개인의 상업적 사용, 재배포와 개작을 허용하고 credit은 불필요하다고 표시하지만, 원 제공처와 VRoidHub에 남은 기타 조건은 그대로 적용됩니다. 이 확인은 `03-OL_Woman.vrm` 한 자산에만 적용하며 다른 VRM·NVA·이미지의 라이선스를 바꾸지 않습니다.

현재 공개 후보와 이 history-free snapshot에는 `rework/master/`의 원본 PNG와 `03-OL_Woman.vrm` 바이너리가 포함되지 않습니다. 이 파일들이 없다는 사실은 앞의 attribution과 원자산 조건을 없애지 않으며, 별도 자산을 다시 포함하거나 재사용하려면 해당 파일의 provenance와 최신 제공처 조건을 다시 확인해야 합니다.

## VRM·배경·상표·책 자료

VRM 또는 배경이 포함된 이미지를 재사용하기 전에 해당 파일의 동봉 metadata와 원 제공처 조건을 확인합니다. 원자산에 재배포 금지, 개작 금지, 출처 표시, 상업적 사용 제한이 있으면 그 조건을 우선합니다. VRoid Project 등 제3자 자료는 원 제공처의 라이선스와 attribution 조건을 보존합니다. 책 원고, 브랜드·상표와 제3자 배경은 이 저장소의 Apache 라이선스로 재허가하지 않습니다.

이 고지는 이 저장소의 코드와 문서에 적용되는 조건을 설명할 뿐, 이미지나 원자산에 독립적인 재사용권을 부여하지 않습니다.

## 검토 한계

일부 이미지는 공개 목업과 제품 화면을 조합한 참고 자료이며, 모든 PNG의 실제 픽셀과 원자산 provenance를 이 문서가 대신 검수하지 않습니다. 원본 저장소의 내부 적대 검토 기록과 `manifest.csv`는 이 history-free 공개 snapshot에 포함하지 않았습니다. 제출 전에 권한 있는 사람이 대표 이미지와 전체 자산의 권리·정보 노출을 직접 확인합니다. 확인되지 않은 자료는 제출하지 않고 `hold`로 둡니다.
