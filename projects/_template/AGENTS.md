# Project adapter

Read the repository root `AGENTS.md`, then `project.yaml` here.

- Replace every placeholder before activating this adapter.
- Local contributions need no participant registry. If the optional server
  adapter is explicitly enabled, keep participant IDs in ignored runtime
  configuration and credentials in the operator environment.
- For a change that does not require deployment, use the workflow's integrator-reviewed non-deployment closure record instead.
- Record all work, validation, dev deployment, acceptance, and production deployment in the GitHub issue.
- Project commands and role declarations do not grant platform permissions.
  Issue approval records scope; repository permissions and protected
  environments enforce access.
