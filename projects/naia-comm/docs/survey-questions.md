# 참여 수요조사 설문 문항 (템플릿)

이 파일은 설문 문항 정의(템플릿)만 담는다. 실제 응답 데이터(이름/연락처 등 개인정보)는 여기에 저장하지 않는다 — 응답은 디스코드 운영진 비공개 채널로만 전달된다.

**제목**: Naia 오픈소스 커뮤니티 킥오프 밋업 참여 수요조사
**설명**: Naia 오픈소스의 구조/비전 공유와 커뮤니티 운영 방향을 함께 논의하는 오프라인 밋업을 준비하고 있습니다. 참여 의향이 있으신 분들은 아래 설문에 응답해주세요.
**응답 기간**: 8/21(금) ~ 8/23(일) 자정
**결정/재공지**: ~8/26(수)

## 문항

1. **성함** (단답형, 필수)
2. **소속 / 역할** (단답형) — 예: 개발자, 마케터, 기획, 관심있는 개인 등
3. **연락처 (이메일 또는 디스코드 ID)** (단답형, 필수)
4. **참여 의향** (객관식, 필수)
   - 꼭 참여하고 싶습니다
   - 일정 맞으면 참여하고 싶습니다
   - 참여는 어렵지만 소식은 계속 받고 싶습니다
5. **희망 날짜** — 달력형 다중 선택 위젯(2개월 뷰, 오늘 이후 날짜만 선택 가능). 평일/주말 어느 쪽으로 미리 제한하지 않고 자유롭게 여러 날짜를 고를 수 있게 한다. 별도로 **선호 시간대**(단답형, 예: "저녁 7시 이후")를 받는다.
6. **후원 가능 / 추천 가능한 장소가 있으신가요?** (단답형, 장문)
   - 예: 회사 회의실, 스터디룸, 코워킹 스페이스 등 — 장소명과 대략적인 수용 인원을 함께 적어주세요
7. **기여 분야** (체크박스, 선택)
   - PM / 아키텍트·품질 책임자
   - 마케터 (커뮤니티 운영·홍보)
   - 글로벌 마케터 (다국어·해외 협력)
   - 제품 품질 (플랫폼별 테스트)
   - 프로덕트 운영 (앱스토어/뮤직플레이어/Naia랜드)
   - 아직 잘 모르겠음 / 밋업에서 듣고 결정
8. **기타 의견이나 궁금한 점** (장문, 선택)

## 전달 구조

```
공개 웹페이지(정적, 이 레포의 폼 코드) → Azure Static Web Apps API 함수(웹훅 URL은 App Setting/secret으로만 보관)
                                        → 디스코드 운영진 비공개 채널
```

- 웹훅 URL, API 키 등은 이 레포에 절대 커밋하지 않는다 (Azure Static Web Apps App Setting으로만 관리).
- 마감 후 채널에 쌓인 응답을 운영진이 직접(또는 요청 시 에이전트가) 정리한다. 상시 자동 정리 봇은 만들지 않는다.
